# Report generation

The delivered PDF is the visually checked reference and embeds its rendered Chinese glyphs. Word uses Noto Sans CJK TC. Rebuilding the report is optional and separate from reproducing data.

Install the optional report dependencies from pyproject.toml, install Noto Sans CJK TC, then run `python scripts/build_report.py --root .`. Convert the resulting Word file to PDF with Word or LibreOffice. Inspect all pages after conversion, because font availability affects layout.

The source chart is generated by matplotlib from reports/m1_summary.json; no image-generation model is used for quantitative data. All five delivered PDF pages were visually inspected.
