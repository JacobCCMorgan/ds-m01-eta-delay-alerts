實際修正

第一張快照改在收到出發事件時建立，避免短程取消被漏掉；未知或撤回的裝置關聯不再視為有效；歷史旅時改採實際出發時間；衍生資料可用時間不得早於任何來源；後續狀態更正也納入來源追溯。

原生 PostgreSQL 的 DDL 與 psycopg 往返檢查程式已提供。此環境沒有原生服務且無法切換一般使用者啟動，因此未宣稱 PostgreSQL 實測通過；完整服務模式對帳仍是下一工程項目。HTTP 通過只涵蓋定位接收及與營運快照的結果一致性。

尚未完成：保留完整 1,800 趟端到端資料、其餘 11 張必要表、基準與 ETA 模型、區間／機率校準、最終模型評估、預警通知與行動追蹤、使用者實機重跑及驗收。

M1 以固定的原始生成時間戳重播資料，另記錄每次指令的實際執行時間。情境日期是合成歷史，不能解讀成模型在 2026 年年初已部署。

4 操作入口與下一階段

建議先閱讀 README.zh-TW.md。Mac 上需 Python 3.11 以上；本輪實測 Linux／Python 3.12.14，未冒稱完成 Mac 實機驗證。資料重跑不需要公司檔案、外部 API key 或付費服務。

入口 | 用途

python -m ds_m01.cli run --root . | 生成 120 趟、快照與標籤、DuckDB／Parquet 及品質檢查

python -m ds_m01.cli http-check --root . | 啟動暫時的本機 HTTP 服務並驗證接收

python -m unittest discover -s tests -v | 執行獨立邊界與整合測試

continuation.json | 本輪完成範圍、限制與下一個工作入口

下一階段先處理 PostgreSQL 實際服務驗證，再將已驗證的生成器擴至 1,800 趟並重跑全量資料品質、切分與標籤成熟檢查；之後才開始模型比較與校準。若服務環境仍不可用，會保留阻礙，並分開記錄可繼續完成的資料工作。

目前不需要使用者再批准例行程式與資料工作。使用者可以針對本報告的代表情境、結果說明及操作可讀性提出調整；GitHub 的簽署 commit 與 push 由使用者處理。

English summary

M1 delivers a reproducible synthetic ETA data pipeline, not a trained forecasting model. The 120-trip trial produces 937 point-in-time snapshots across 17 canonical tables. Independent arrival evidence, time-aware joins, immutable promises, and restricted historical labels are checked. Local HTTP ingestion and fresh rebuild parity pass; native PostgreSQL execution remains unverified. No business impact or real-fleet accuracy is claimed.
