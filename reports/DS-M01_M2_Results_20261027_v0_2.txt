可用目標要求到場答案已在該組截止前確認，且快照時剩餘旅時為正。取消、未成熟與實際已到場的快照仍保留供稽核；不把未知填成零或準時。「已到場」也可能表示當時到場通知尚未送達，不能倒用事後資訊移除快照。排除組即使有合格標籤，也不納入訓練、校準或測試。

樣本限制：未見路線僅 29 趟可用行程；未見車輛及路線僅 4 趟可用行程。小群結果須分開呈現並揭露不確定性，不能只看快照總數。

訓練組另有 97 張可用目標快照沒有當時已知的訓練歷史池。M3 必須定義明確的無支援或備援策略；本輪的樣本門檻只是描述性提示，並非統計檢定力或上線驗收標準。

同趟快照彼此相關，模型驗證與不確定性估計須按行程分組。測試組本輪僅檢查資料有效性與覆蓋，不得據此選模型、特徵、校準方法或預警門檻。

本輪工程調整

歷史關聯與來源追溯改為逐筆寫入，並以行程及租戶索引減少重複掃描；保留全部符合時間條件的歷史，沒有用抽樣縮減資料。輸出先寫暫存檔，完成並關閉後再逐檔發布，避免建置中途失敗覆蓋既有完整檔案。

M1 的生成器、種子、實體編號及特徵定義沿用。M2 取得時間與執行時間分開記錄；舊資料業務內容可對照，新的歷史池則隨全量訓練行程擴大。

28 張必要表均已建立明確型別，其中 11 張模型、預測、輸出發布、預警通知與行動追蹤表為空表。表結構齊備不等於模型或預警流程完成；本輪沒有產生虛構預測或通知紀錄。

3 重跑方式與 M3 入口

在解壓後的專案根目錄執行。需 Python 3.11 以上；已交付固定依賴版本與 M2 設定。重跑會更新生成資料與執行紀錄，請保留原始交付包作為參考快照。完整資料解壓約 12.6 GB；完整重建對帳建議預留約 30 GB 磁碟空間。

python3 -m venv .venv

source .venv/bin/activate

python -m pip install -r requirements.lock

python -m pip install -e . --no-deps

python -m ds_m01.cli run --root . --config config/m2.json

python -m ds_m01.cli http-check --root . --config config/m2.json

python scripts/check_m2_readiness.py --root .

python scripts/check_rebuild.py --root . --config config/m2.json

python -m unittest discover -s tests -v
